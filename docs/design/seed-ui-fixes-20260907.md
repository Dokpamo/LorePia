# SEED 검토 후 UI 수정 및 검증

2026-09-07 · 작업 ID `UI-SEED-FIXES-20260907`

[추가 검토](seed-ui-final-review-20260907.md)의 1–4번을 격리된 `ui-preview.html`에 반영했다. 폴더로 묶는 버튼 추가는 사용자 요청으로 제외했고, 기존 드래그 및 문맥 메뉴 동작은 그대로 두었다.

## 변경

- **하단 요소 배치:** 복사 알림과 최근 메시지 버튼이 입력바 위의 공통 영역을 사용한다. 높이가 짧은 화면에서는 알림과 버튼을 나란히 배치해 열 줄 입력 상태에서도 겹침을 피한다. 포커스 이동 때문에 전체 페이지가 가로로 밀리던 현상도 루트의 `overflow: clip`으로 막았다.
- **보낸 메시지 편집:** 편집 중에는 원래 메시지를 유지하고 완료할 때 새 분기를 만든다. 변경 후 뒤로가기 버튼, Escape, 오른쪽 스와이프는 계속 수정하거나 변경을 버릴 수 있는 확인을 제공한다. 원래 대화와 이후 응답은 원래 분기에 남는다. 공백 메시지와 다른 분기에서 열린 오래된 편집 콜백은 적용하지 않는다.
- **이름 검증:** 기존 캐릭터 이름과 대화 이름에 필수 표시와 공백 오류 안내를 연결했다. 전체화면 편집 완료와 설정 저장에서 검증한다. 새 캐릭터·대화의 기본 이름 사용은 유지한다.
- **다크 모드 보조 글자:** 보조 정보, 긴 설명, 입력 힌트를 별도 토큰으로 나눴다. 피스타치오 주 버튼과 중립 선택 배경은 유지한다.

설정 필드, 검색, 작성 중인 메시지의 기존 초안 반영 방식은 그대로다. 이번 수정은 메모리 샘플 UI에 한정되며 라이브 렌더러, Rust, IPC, 스키마, 의존성을 변경하지 않았다.

별도 브라우저 테스트의 오류 로그는 없었다. Tauri 앱을 새 빌드로 열고 사용 중이던 도윤 관리 화면과 확인된 작성 초안을 복원했다. 모바일 소프트 키보드와 VoiceOver·TalkBack은 이번에 검증하지 않았다.

## 대비

이전 검토와 같은 공식 APCA 0.0.98G 계산에서, 다크 보조 글자 `#C4C4CA`는 사용 중인 중립 배경에 대해 Lc 절댓값 63.96–70.17이다. 긴 설명 `#D4D4D8`는 해당 설명에 쓰이는 배경 `#17171A`, `#252528`, `#303034`에서 75.48–79.63이다. 실제 브라우저의 캐릭터 소개 색도 `rgb(212, 212, 216)`으로 확인했다. 입력 힌트는 기존 톤을 유지한다. 주 버튼의 `#CDDEA4`도 유지했다.

이는 해당 색상 조합의 보완 결과이며 전체 접근성 준수를 인증하는 의미는 아니다. 기준과 계산 출처는 [이전 검토의 대비 항목](seed-ui-final-review-20260907.md#4-다크-모드의-작은-보조-글자가-seed의-대비-기준에-못-미친다--측정)에 기록했다.
