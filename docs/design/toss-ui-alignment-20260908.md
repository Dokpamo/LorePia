# LorePia 상단 정렬·화면 밀도·설정 조작 개선

Task: UI-TOSS-20260908. 기준 커밋/merge-base: `6f22761a4305443541452e7409639114f4c10dfd`.
기존 변경이 많은 `codex/tauri-chat-preview` 작업 트리에서 UI 비교 분석의 후속 개선을 수행했다.
관련 분석: [토스 UI 비교](../reviews/toss-ui-comparison-20260908.md).

## 적용한 규칙

- 캐릭터 열과 상단 내비게이션이 같은 중심축을 사용한다. 기본 열 72px, 버튼 48px, 좌우 여백 12px이다. 작은 화면에서도 열과 버튼의 실제 너비 차이로 여백을 계산한다.
- 393px를 기준으로 화면 밀도를 `clamp(0.9, width / 393, 1)`로 계산한다. 글자·아이콘·간격·주요 행·배너에 함께 적용한다. 페이지 좌표에는 확대 transform을 적용하지 않으므로 제스처와 입력창 전환이 같은 좌표계를 사용한다.
- 터치 영역은 최소 44px, 보조 글자는 기본 설정에서 최소 12px로 유지한다. 편집 입력은 모바일 WebKit의 포커스 확대를 피하도록 16px 이상을 유지한다.
- 큰 글자 설정의 배율은 밀도와 별도로 곱한다. 높이만 바뀌면 배너의 크기는 유지되며, 글을 볼 수 있는 영역과 입력바의 최대 높이가 달라진다. 넓은 화면에서는 밀도 1로 열과 내용 영역을 확장한다.
- 설정 페이지 제목은 26/35, 상세 정보 제목은 22/31, 설정 그룹 제목은 17/25.5로 구분한다. 본문 17, 현재값·설명 15, 날짜 13의 역할을 유지한다. 위 수치에는 밀도와 사용자의 큰 글자 설정이 적용된다.
- 검색 입력과 뒤로가기를 같은 내비게이션 줄에 놓았다. 전체화면 작성의 축소·전송도 같은 상단 버튼 축을 사용한다.
- 입력바 도구 영역은 실제 높이와 여백으로 측정한다. 충분한 높이에서 10줄까지 표시하고 이후 스크롤하며, 짧은 화면에서는 상단 이동과 도구가 남도록 제한한다.
- AI 설정은 동일값 선택과 원래값으로 복귀를 실제 변경으로 취급하지 않는다. 중단된 응답 보존은 인라인 스위치로 편집하고 기존 저장 정책을 따른다. 보존만 변경할 때 레거시 프로필이나 하위 화면에서 저장된 대상이 지워지지 않는다.
- 저장은 피스타치오, 요청 미리보기는 중립색으로 표현한다. 연결·모델·프리셋과 고급 관리 그룹을 분리했다. 확인창의 왼쪽 회색/오른쪽 권장 동작 규칙을 유지한다.

이 값은 [TDS Typography](https://tossmini-docs.toss.im/tds-react-native/foundation/typography/)와 첨부 화면을 참고해 정한 LorePia의 규칙이다. 창 밀도나 393px 기준을 토스의 의무 규격으로 해석하지 않는다.

- 320px에서 높이 696→552px 변경: 배너 약 100.8px, 본문 15.3px 유지. 화면 네 변에 추가 여백 없음.
- 320px 큰 글자: 본문 16.83px, 제목 25.74px로 기본 대비 1.1배.
- 320×552 입력바: 10줄의 실제/표시 높이 263px, overflow hidden. 11줄 실제 높이 289px, overflow auto. 설정·확대·전송 버튼은 같은 Y, 모두 44×44px.
- 320×552 전체화면 작성: 축소·전송 버튼의 Y=5px, 양쪽 여백 동일. 검색창과 뒤로가기 역시 Y=5px, 높이 44px.
- 760px 두 열 300+460px, 1120px 세 열 336+504+280px: 가로 여백이나 겹침 없이 뷰포트를 채운다.
- 실제 Tauri 앱에서 스위치를 마우스와 스페이스 키로 변경·복귀했고, 동일 모델을 다시 선택해도 저장이 비활성 상태이며 이탈 확인 없이 돌아간다.

프런트엔드 전체 127개 파일/939개 테스트 통과 후, 검색의 상단 배치를 추가하고 관련 6개 파일/45개 테스트를 다시 통과했다. Lua/regex 회귀 검사, 전체 형식·i18n·ESLint 검사, 타입 검사(오류 0, 기존 ChatPane 경고 2), IPC 생성 및 소스 아키텍처 검사도 확인했다. Tauri UI 앱을 다시 빌드했다.

Rust/DTO/IPC/저장 경계를 변경하지 않았다. 기존 채팅 초안은 앱 갱신 후 복원하며, 검증을 위해 실제 메시지를 전송하거나 사용자 설정을 저장하지 않았다.

## 제목 크기 후속 조정

사용자의 제목이 크다는 피드백에 따라 설정 페이지 제목을 26/35에서 22/31로,
캐릭터·채팅방 및 상세 제목을 22/31에서 20/28로 낮췄다. 본문과 설정 그룹의 크기는 유지한다.
위 표는 최초 개선 당시의 측정이며, 이 조정 이후 320px 기본 화면에서 페이지 제목은
19.8px, 캐릭터 제목은 18px, 본문은 15.3px이다. CSS 형식 검사와 Tauri UI 재빌드를 확인했다.
