## Implemented contract and evidence

- Baseline: existing Markdown suite, 1 file / 9 tests PASS. The independent c999c43 probes established the four 60KB budget bypasses and both closed/unclosed 513-line losses before edits.
- Whole-tree budget: 4096 render units count block elements, formatted inline elements, text nodes, list items and quote-line paragraphs. Two units are reserved for one paragraph/text fallback. If a block cannot fit, its partially constructed tree is discarded and its exact source suffix is displayed literally. Svelte's private comment anchors are implementation overhead, not admitted markup; tests count actual rendered elements and nonempty text nodes. No text becomes raw HTML.
- Fences: removing the 512-body-line break retains the code state and all 511/512/513/514 lines, closed or still streaming. Input bytes remain bounded by the original 256KiB formatted-input ceiling. Lists/quotes/paragraphs retain their 512-line grouping behavior.
- Incremental: completed blank lines outside a fence provide stable prefix checkpoints (offset/block count/remaining budget). One parser per MarkdownText retains only its latest input, output and stable prefix. Append byte accounting handles a high/low surrogate split; edits/truncation reset; over-limit input uses the existing whole-source literal fallback. Full and incremental use the same suffix parser with the same remaining whole-message budget.
- Tests: 3 files / 29 tests PASS. Four 60KB inputs satisfy the element/text render bound and source remainder checks; nested-budget fallback is exact. Mutable syntax and partial Unicode are checked at every prefix for examples and 64 deterministic mixed inputs. Budget/512-group boundaries, edits, truncation, byte-ceiling transitions, actual Svelte rerender and identical-input reuse are covered.
- Work evidence: 1500 finalized paragraphs in 500 updates submit 4500 characters total to suffix parsing and byte scanning, preserving block identity. A 60KB / 500-update stream creates at most 2548 block objects and scans 60000 characters for byte accounting, compared with the old full-prefix probe's 5,010,000 blocks /15,030,000 bytes.
